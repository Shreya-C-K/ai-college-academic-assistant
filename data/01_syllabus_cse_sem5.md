# NMAM  Institute of Technology - B.Tech CSE (AI & ML) Syllabus, Semester 5 (AY 2026-27)

Total credits registered in Semester 5: 25 (6 theory courses, 2 labs, 1 mini project).

## CS501 - Design and Analysis of Algorithms (4 Credits)
Prerequisites: Data Structures, Discrete Mathematics.
Objective: Teach students to design efficient algorithms and analyse their time and space complexity.
- Unit 1 - Algorithm Analysis: asymptotic notation, recurrence relations, master theorem, amortized analysis.
- Unit 2 - Divide and Conquer and Greedy: merge sort, quick sort, Strassen's multiplication, activity selection, Huffman coding, fractional knapsack.
- Unit 3 - Dynamic Programming: 0/1 knapsack, longest common subsequence, matrix chain multiplication, Floyd-Warshall, optimal BST.
- Unit 4 - Graph Algorithms: BFS and DFS applications, minimum spanning trees (Prim, Kruskal), shortest paths (Dijkstra, Bellman-Ford), max flow (Ford-Fulkerson).
- Unit 5 - Backtracking and NP-Completeness: N-Queens, graph colouring, branch and bound, P vs NP, NP-complete problems, reductions, approximation algorithms.
Textbooks: Cormen et al., Introduction to Algorithms; Levitin, Introduction to the Design and Analysis of Algorithms.

## CS502 - Database Management Systems (4 Credits)
Prerequisites: Data Structures, Discrete Mathematics.
Objective: Build strong foundations in relational database design, querying, transactions and storage.
- Unit 1 - Introduction and ER Modelling: database architecture, data independence, ER and EER diagrams, mapping ER to relational schema.
- Unit 2 - Relational Model and SQL: relational algebra, SQL DDL/DML, joins, subqueries, views, triggers, stored procedures.
- Unit 3 - Normalization: functional dependencies, 1NF, 2NF, 3NF, BCNF, lossless decomposition, dependency preservation.
- Unit 4 - Transaction Management: ACID properties, schedules, serializability, concurrency control (2PL, timestamp ordering), deadlocks, recovery (log-based, ARIES).
- Unit 5 - Storage, Indexing and NoSQL: file organization, B and B+ trees, hashing, query processing and optimization, intro to MongoDB and key-value stores.
Textbooks: Silberschatz, Korth and Sudarshan, Database System Concepts; Elmasri and Navathe, Fundamentals of Database Systems.

## CS503 - Operating Systems (3 Credits)
Prerequisites: Computer Organization, C Programming.
Objective: Explain how an operating system manages processes, memory, files and devices.
- Unit 1 - Introduction: OS structures, system calls, processes, threads, process control block.
- Unit 2 - CPU Scheduling and Synchronization: FCFS, SJF, Round Robin, priority, multilevel queues, critical section problem, semaphores, monitors, classical problems.
- Unit 3 - Deadlocks: deadlock characterization, prevention, avoidance (Banker's algorithm), detection and recovery.
- Unit 4 - Memory Management: paging, segmentation, virtual memory, demand paging, page replacement (FIFO, LRU, Optimal), thrashing.
- Unit 5 - Storage and File Systems: file system structure, allocation methods, disk scheduling (SSTF, SCAN, C-SCAN), RAID, protection and security basics.
Textbooks: Silberschatz, Galvin and Gagne, Operating System Concepts; Tanenbaum, Modern Operating Systems.

## CS504 - Machine Learning (4 Credits)
Prerequisites: Linear Algebra, Probability and Statistics, Python Programming.
Objective: Introduce supervised, unsupervised and ensemble learning with hands-on model building.
- Unit 1 - Foundations: types of learning, bias-variance tradeoff, train/validation/test split, cross-validation, evaluation metrics.
- Unit 2 - Regression and Classification: linear and logistic regression, regularization, k-NN, naive Bayes, decision trees, SVM.
- Unit 3 - Ensemble Methods: bagging, random forests, boosting (AdaBoost, Gradient Boosting, XGBoost).
- Unit 4 - Unsupervised Learning: k-means, hierarchical clustering, DBSCAN, PCA, t-SNE, anomaly detection.
- Unit 5 - Neural Networks Basics: perceptron, backpropagation, activation functions, CNN overview, introduction to model deployment.
Textbooks: Bishop, Pattern Recognition and Machine Learning; Geron, Hands-On Machine Learning with Scikit-Learn and TensorFlow.

## CS505 - Computer Networks (3 Credits)
Prerequisites: Operating Systems basics.
Objective: Understand layered network architecture, protocols and network design.
- Unit 1 - Introduction and Physical Layer: OSI and TCP/IP models, transmission media, switching, multiplexing.
- Unit 2 - Data Link Layer: framing, error detection (CRC), flow control, ARQ protocols, Ethernet, CSMA/CD, Wi-Fi basics.
- Unit 3 - Network Layer: IPv4 and IPv6 addressing, subnetting, routing (RIP, OSPF, BGP), NAT, ICMP.
- Unit 4 - Transport Layer: UDP, TCP connection management, flow control, congestion control.
- Unit 5 - Application Layer and Security: DNS, HTTP, SMTP, FTP, basics of cryptography, TLS, firewalls.
Textbooks: Kurose and Ross, Computer Networking: A Top-Down Approach; Forouzan, Data Communications and Networking.

## CS506 - Professional Elective I: Generative AI and LLM Applications (3 Credits)
Prerequisites: Machine Learning (co-requisite), Python Programming.
Objective: Build practical applications using large language models, retrieval and agents.
- Unit 1 - Transformers and LLMs: attention, tokenization, pre-training, fine-tuning, prompting techniques.
- Unit 2 - Embeddings and Vector Search: text embeddings, similarity metrics, vector databases (FAISS, Chroma).
- Unit 3 - Retrieval-Augmented Generation: chunking strategies, retrievers, RAG pipelines, evaluation and hallucination control.
- Unit 4 - Agents and Orchestration: LangChain, tool calling, LangGraph workflows, memory.
- Unit 5 - Responsible AI and Deployment: bias, safety, privacy, prompt injection, cost and latency optimization.
Textbooks: Jurafsky and Martin, Speech and Language Processing (draft chapters); LangChain and LangGraph official documentation.

## CS551 - Database Management Systems Laboratory (1 Credit)
Weekly 3-hour practical. Covers DDL/DML in MySQL, joins and subqueries, PL/SQL procedures and triggers, normalization exercises, and a small MongoDB assignment. Lab record is mandatory for the end-semester practical exam.

## CS552 - Machine Learning Laboratory (1 Credit)
Weekly 3-hour practical in Python with scikit-learn. Covers data preprocessing, regression and classification models, ensemble methods, clustering, and a Kaggle-style mini challenge.

## CS553 - Mini Project (2 Credits)
Teams of 2 to 3 students build an application on a faculty-approved problem statement. Milestones: synopsis (Week 3), Review 1 (Week 7), Review 2 (Week 12), final demo and report (Week 15).
